# Rubicon Maps v1.0.1 (2026-03-25)

**Filters Learn Some Manners**

Rubicon Maps v1.0.1 turns the first post-v1 improvement cycle into a proper release. The main focus is the module filter experience: searchable multi-select pickers, better Divi 5 interaction patterns, and release metadata that now actually matches the shipped code.

## Added

- Searchable multi-select filter pickers with pill tokens for Divi 5 map and listing modules
- Structured filter value helpers that preserve compatibility with legacy comma-separated module values
- Divi 4 builder-side enhancement support for searchable category, region, and explicit-location filters

## Changed

- Promoted plugin metadata and repository release references to `1.0.1`
- Improved the Divi 5 picker interaction model with open-on-click dropdowns, checkbox rows, fixed-height scrolling, and footer actions

## Fixed

- Closed the release hygiene gap so changelog, readmes, packaged artifacts, and release metadata reflect the shipped post-v1 changes

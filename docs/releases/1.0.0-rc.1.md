# Rubicon Maps v1.0.0-rc.1 (2026-03-17)

**The Candidate Stops Wandering**

This release candidate marked the point where Rubicon Maps had a coherent v1 shape: Leaflet-first maps, linked map/list behavior, the split Divi 4 and Divi 5 runtimes, and installable packaging instead of ad hoc source snapshots.

## Added

- Release packaging and verification scripts for installable plugin zip artifacts
- Forgejo updater and lifecycle support for release-based updates
- Canonical release-candidate metadata across plugin headers, changelog, and readmes

## Changed

- Promoted the plugin metadata to the `1.0.0-rc.1` release-candidate state
- Clarified the Leaflet-first support boundary for the initial v1 line

## Fixed

- Release metadata alignment so the candidate package and repository docs referenced the same pre-release version

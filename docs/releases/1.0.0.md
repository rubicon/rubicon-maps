# Rubicon Maps v1.0.0 (2026-03-18)

**Maps, Meet Manners**

Rubicon Maps has stopped acting like a promising release candidate and started acting like a product you can actually ship. v1.0.0 delivers the Leaflet-first mapping workflow, linked map/list behavior, hardened admin flows, and installable release packaging that the plugin has been converging on.

## Added

- CSV import/export with the canonical Rubicon Maps location schema
- Dedicated Divi 4 and Divi 5 runtime support
- Admin geocoding helper with address autocomplete support
- Popup behavior controls and marker clustering for Leaflet maps
- Fixed-height synced listing behavior and cleaner default list output
- Release packaging and verification scripts for installable zip artifacts

## Changed

- Promoted plugin metadata and documentation to the stable `1.0.0` release state
- Clarified the Leaflet/OpenStreetMap support boundary for v1
- Aligned frontend map/list runtime behavior with the current Divi-first product scope

## Fixed

- Safer popup output escaping in the frontend layer
- More reliable media picker behavior in admin mapping screens
- Cluster-aware list-to-map syncing so clicking a list item opens clustered markers correctly
- Cleaner default list rendering without browser bullet styling

## Security

- Routes admin geocoding through authenticated WordPress AJAX with nonce protection

# Support

Thanks for using Rubicon Maps.

## Getting help

- **Questions and usage help:** open a [GitHub Discussion](https://github.com/rubicon/rubicon-maps/discussions) (if enabled) or a GitHub issue with the `question` label.
- **Bugs:** open a GitHub issue with clear reproduction steps, plus your WordPress, PHP, and Divi versions and the plugin version.
- **Feature requests:** open a GitHub issue describing the use case and the outcome you want.
- **Security vulnerabilities:** do **not** open a public issue — follow [SECURITY.md](SECURITY.md).

## Before you file

- Confirm you are on the latest release.
- Search existing issues to avoid duplicates.
- Include what you expected to happen and what actually happened.

This is an open-source project maintained on a best-effort basis; response times
vary.
